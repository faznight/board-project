# Доска объявлений — Board

Учебный проект по разработке веб-приложения. Вариант 16.

## Описание проекта

Board — веб-приложение для размещения и просмотра объявлений. Пользователи могут регистрироваться, публиковать объявления, искать предложения и управлять собственными публикациями.

## Используемые технологии

- **Python** — основной язык программирования.
- **FastAPI** — создание API и обработка HTTP-запросов.
- **SQLAlchemy 2.0** — работа с базой данных.
- **SQLite** — хранение данных.
- **Alembic** — управление миграциями базы данных.
- **Pydantic** — проверка входящих данных.
- **HTML, CSS, JavaScript** — клиентская часть приложения.
- **Fetch API** — взаимодействие frontend с backend.

## Основные возможности

- Регистрация, вход и выход из аккаунта.
- Хранение паролей в виде хешей с солью.
- Общая лента объявлений всех пользователей.
- Просмотр собственных объявлений.
- Создание, редактирование и удаление своих объявлений.
- Категории объявлений.
- Поиск по названию и описанию.
- Фильтрация по категории и цене.
- Сортировка по дате и стоимости.
- Пагинация результатов.
- Статистика по объявлениям и категориям.
- Ограничение доступа к операциям с чужими объявлениями.

## Установка и запуск

1. Склонировать репозиторий:

```bash
git clone https://github.com/faznight/board-project.git
cd board-project
```

2. Создать виртуальное окружение:

```bash
python -m venv .venv
```

3. Активировать его в Windows:

```powershell
.venv\Scripts\activate
```

4. pip install fastapi uvicorn sqlalchemy alembic jinja2 python-multipart itsdangerous python-dotenv:

```bash
pip install fastapi uvicorn sqlalchemy alembic jinja2 python-multipart itsdangerous
```

5. Выполнить миграции базы данных:

```bash
python -m alembic upgrade head
```

6. Запустить сервер:

```bash
python -m uvicorn app.main:app --reload
```

7. Открыть приложение в браузере:

http://127.0.0.1:8000

Документация API доступна по адресу:

http://127.0.0.1:8000/docs

## API

Основные группы маршрутов:

- `/api/auth/` — регистрация, авторизация и выход.
- `/api/ads/` — работа с объявлениями.
- `/api/categories/` — работа с категориями.
- `/api/health` — проверка состояния сервера.

## База данных

В проекте используется SQLite. Создание и изменение таблиц выполняется с помощью миграций Alembic.

## Назначение

Проект разработан в рамках учебной практики для изучения создания веб-приложений, REST API, работы с базами данных, авторизации пользователей и взаимодействия клиентской и серверной частей.
